# 分类排表与肾表布局

本规范描述应用的通用导出布局。

- 等线11号字，文字居中、垂直居中、细边框，金钱数字保留两位，适当列宽和行高，长名称换行。不要塞多个名字进同一格，不输出QQ号作为CN替代。
- 每个大类一个Sheet，命名与大类相同。
- 拼团类左侧为角色横向排队表：首行合并标题显示大类及盒号，次行为各角色；自第三行起按原始评论时序逐个填写CN。数量N连续占N格，之后保留已开配数对应的空位。多盒纵向分块。
- 拼团类右侧留一空列，再按人整理“cn / 制品 / 均价 / 调价 / 单价 / 总计”。同人多件各占一行，合并CN与总计区域，总计只写一次。固定价类显示其固定单价，不伪造均价。
- 单领类：cn / 制品 / 原价 / 折后 / 总计。特典类：cn / 特典 / 单价 / 总计。按人连续排，CN合并，逐人总计只出现一次；仅排表阶段的折后列使用当前已保存价格，不自行应用尚未确认的优惠。
- 最终肾表与应用预览：cn / 制品 / 总价。同一收款对象的同款同价商品汇总一行，如“通行证-角色 ×15对”；按首次出现顺序显示，数量1可不标。不同商品编号、分盒、计价或代排对象不能合并。同一个人的CN与总价按完全相同的起止行纵向合并，金额保留在合并区域首格。本人及每位群外代排对象独立成块、独立计费，位置相邻。分类明细和队列仍逐件保留，用原始明细计算总额及Excel公式，不因展示压缩丢件。SET作为一套独立商品，不展开为多条再次收费。
- 肾表导出附“折算统计”：原价合计、实付合计、购物金购入/面额、购物金折合金额、特典抵扣、扣特典后商品成本、最终比例、应收与成本差额。顺序必须先购物金、后特典。
- Excel使用可追溯公式和缓存值，设置打开重算；跨表比例用绝对引用。空白、0和未知价格分开，未知显示待定价，不让SUM把缺失当已结清。
